# 🎮 Simon Says Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasingly longer sequence of colors. Each successful round increases the difficulty by adding a new color to the sequence.

## 🚀 Features

- Interactive gameplay with four colored buttons
- Random sequence generation
- User input validation
- Increasing difficulty with each level
- Visual button animations
- Score/level tracking
- Game over screen with restart option
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Handling

## ▶️ How to Play

1. Open the game in your browser.
2. Press any key to start the game.
3. Watch the highlighted color sequence.
4. Repeat the sequence by clicking the buttons in the same order.
5. Each correct sequence advances you to the next level.
6. The game ends if you click the wrong button.
7. Press any key to restart.
